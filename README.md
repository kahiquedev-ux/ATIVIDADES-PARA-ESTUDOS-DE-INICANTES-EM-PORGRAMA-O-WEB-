# PROJETOS DE SITES EDUCATIVOS

Este repositório contém uma coleção de projetos de sites desenvolvidos com fins educativos, seguindo uma apostila de estudos. Os projetos simulam diferentes tipos de negócios e sistemas simples de páginas web.

PROJETOS INCLUÍDOS:

* Site de Bolos
* Floricultura
* Jogo de Luta
* Petshop
* Padaria
* E-commerce
* Pizzaria
* Supermercado

FINALIDADE DOS PROJETOS:

Esses projetos foram desenvolvidos com o objetivo de:

* Praticar desenvolvimento web (HTML, CSS e JavaScript)
* Simular sites reais de diferentes áreas comerciais
* Servir como material de estudo e aprendizado
* Demonstrar estrutura básica de sites funcionais
* Serem usados apenas para fins educativos

IMPORTANTE:

Esses sistemas não são comerciais reais, podendo ser colocados no ar apenas para demonstração e aprendizado. Em alguns casos, podem ser usados como base para projetos maiores.

ACESSO ADMINISTRATIVO:

* O acesso administrativo dos sites é feito via JavaScript
* As funções de controle estão implementadas diretamente no código
* Não há banco de dados ou backend real (projeto educativo)

COMO USAR O PROJETO:

1. Baixe o arquivo ZIP
2. Extraia o conteúdo no seu computador
3. Abra a pasta do projeto
4. Clique duas vezes no arquivo index.html
5. O site será aberto no navegador

OBSERVAÇÃO:

Esses projetos seguem uma apostila de aprendizado e podem ser usados como base para estudos de desenvolvimento web.
